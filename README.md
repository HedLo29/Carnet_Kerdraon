# Le bureau du Professeur

Scène finale du jeu **Les Archives Englouties de l'Île d'Ys** : le *Carnet des marées* du Pr Kerdraon, à feuilleter page par page (douze folios rassemblés dans les salles), et l'insigne néon « Gardien·ne du Flot » en 3D sur la dernière page.

Page autonome (`index.html`) publiée avec GitHub Pages, à intégrer dans Moodle par un lien ou une iframe.
